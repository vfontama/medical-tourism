# CareBridge India + Turkey Project Brief

## Purpose

CareBridge India + Turkey is a mobile-first PWA prototype for African patients and caregivers planning medical travel to India or Turkey.

## Core User Flows

- Search for hospitals and clinics by specialty.
- Compare provider ratings and cost bands.
- Contact providers by website, phone, or WhatsApp where available.
- Compare flight options from African cities to the selected provider's nearest airport.
- Create in-app flight and hotel booking requests with local confirmation references.
- Prepare a care concierge request with patient notes.

## Current Implementation

- Static HTML, CSS, and JavaScript.
- PWA manifest and icon.
- No backend or live booking API yet.
- Provider, flight, and accommodation data are seed/demo data.

## Production Next Steps

- Replace seed provider data with a verified provider database.
- Add secure user accounts and consent flow.
- Integrate airline, hotel, payment, passport, visa, and medical-record APIs.
- Add privacy controls for medical information.
- Package as Android/iOS app with Capacitor or rebuild in React Native/Expo.
